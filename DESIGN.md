# Power Window interface

A practical energy planner with quiet, warm surfaces and clear evergreen actions. Use the same navigation and visual vocabulary in the browser and Android web app.

- Three primary destinations: Planner, Compare tariffs, Statistics. Guides and product information live in More. Language switching preserves the paired route.
- On desktop, place planning controls beside results. On mobile, show the recommendation first with a direct link to change the appliance or day; keep primary navigation at the bottom.
- Keep estimated cost, data status, and the assumptions behind the recommendation visible. Provide an expandable hourly table alongside the visual chart.
- Use native form controls and disclosure elements. Saved setups, EV details, cost assumptions, and grid diagnostics should not compete with the answer.
- Use system sans typography, background `#f5f6f2`, ink `#172e2b`, secondary text `#5b6b63`, borders `#d9dfd6`, and active green `#176b50`. The recommendation uses `#173e30` with light text.
- Give controls at least 44px touch targets, visible keyboard focus, accessible names, and reduced-motion support. Mark live, cached, demonstration, loading, and unavailable data accurately.

The implementation lives in styles.css, navigation.css, navigation.js, and the static route markup. Product facts and scope decisions live in PRODUCT.md.
